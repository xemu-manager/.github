# Xemu Manager

**A game library manager and launcher for the xemu Original Xbox emulator.**

Cross-platform, with first-class support for Linux and the Steam Deck.

</div>

---

## Projects

| Project | Description | Platforms | Status |
|---|---|---|---|
| [Xemu Manager](https://github.com/xemu-manager/xemu-manager) | Game library, one-click launch and guided first-time setup for [xemu](https://xemu.app) | Windows, Linux, Steam Deck, macOS | Early development |

## What it aims to do

- Scan folders for Xbox ISOs and show each game's title and box art
- Launch any game in xemu without browsing for files
- Guide the first-time setup (boot ROM, BIOS, hard disk image, EEPROM) using your own dumps
- Per-game settings, xemu install and updates, Steam and Steam Deck integration

Built with C# / .NET 10 and [Avalonia UI](https://avaloniaui.net).
